# Code of Conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

It applies to all project spaces: the issue tracker, pull requests, discussions
and any other channel where the project is represented.

## Reporting

Report unacceptable behaviour to **onur@omelas.tech**. Reports are read only by
the maintainers listed in [MAINTAINERS.md](MAINTAINERS.md) and are kept
confidential. You should receive a reply within three working days.

The project currently has a single maintainer. If your report concerns that
maintainer, you can instead
[report it to GitHub](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
Once there is more than one maintainer, a maintainer named in a report takes no
part in handling it.
