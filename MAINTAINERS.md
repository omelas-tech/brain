## Co-maintainers wanted

The project has one maintainer today and would like more, particularly from
other organisations. If you use Brain Memory and want to help steer it, the
areas that would benefit most from an owner are:

- **Agent integrations**: keeping the plugins for individual agents current as
  those agents change
- **The memory file format**: specification, schema and conformance tests
- **The benchmark harness**: reproducing and extending the recall benchmarks

Open an issue or write to onur@omelas.tech.
